# Motion Lab

ブラウザだけで画像・動画素材を作成できるクリエイティブツール集です。

## 起動

`index.html` をブラウザで開き、ホーム画面からツールを選択します。処理はブラウザ内で完結します。

各ツールの設定はブラウザのローカルストレージへ自動保存され、次回表示時に復元されます。読み込んだ画像ファイルと再生位置は保存されません。
Dial TypeとText Reelで選択したローカルフォントはブラウザ内のIndexedDBへ保存され、外部には送信されません。

## Outline Motion

- PNG / WebP / GIF のアルファチャンネルから最大の連結要素を抽出
- プレビュー上のクリックによる輪郭始点の変更
- 輪郭の先頭と末尾をそれぞれ任意のパーセント間でアニメーション
- 100%を超える値による複数周の指定
- 再生速度、出力時間、イージング、線、背景、元画像濃度の調整
- 最大90秒、1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力

## Dial Type

- 入力した文字列をダイヤル錠風に表示
- 前後1文字から目的の文字へ戻るアニメーション
- 動かさない文字の個別指定
- 濁点・半濁点を右肩へ固定し、小書き文字を自動固定
- 初期方向、ずれ数、表示段数、復帰順、時間差、速度、イージング、ローカルフォント、配色の調整
- 固定文字と復帰済み文字を赤で表示し、中央の読取位置を枠で表示
- 最大90秒、1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力

ホーム画面では、ツールを「画像・輪郭」「文字・タイポグラフィ」「漢字・画」の3系統に分けて表示します。

## Kanji Writer

- 普通・ランダム・逆の3つの画順モードで漢字1文字を描画
- 普通とランダムは各画を始点から終点へ、逆は最後の画から最初の画へ終点から始点へ描画
- ランダムモードの手動シャッフルと再生ごとの再抽選に対応
- Hanzi Writer Japanese Dataの画輪郭と運筆中心線を利用
- 最大60秒の全体時間、画ごとのインターバル、イージング、下書き濃度、文字色、背景色の調整
- 400 x 400または800 x 800、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力
- 日本語用のHanzi Writer Japanese Data（AnimCJK / Arphic Public License・LGPL）を使用（取得後はブラウザ内にキャッシュ）

## Random Kanji

- 漢字1文字を画ごとに分解し、シャッフルした順番で表示
- 1回に表示する画数を1画から文字の全画数まで指定
- 全体時間内で繰り返し、各巡で順番と複数画の組み合わせを再抽選
- 画を積み上げて完成させる表示と、セットごとに入れ替える表示に対応
- フェードまたは瞬時の切り替え、手動シャッフル、再生ごとの自動シャッフルに対応
- 最大60秒の全体時間と、初期値1秒の切り替え間隔を個別に調整
- 下書き濃度、文字色、背景色、プレビュー速度の調整
- 400 x 400または800 x 800、60fps、WebM形式の動画出力と指定時刻のPNG出力
- Kanji Writerと同じ日本語用のHanzi Writer Japanese Dataを使用（取得後はブラウザ内にキャッシュ）

## Color Focus

- イラストを赤・橙・黄・緑・青緑・青・紫・桃・白黒の9系統へ分類
- 選択した色系統だけを着色し、それ以外をグレースケール化
- 非選択部分をモノクロまたは完全透過へ切り替え
- プレビュー上のクリックによる色系統の選択
- 色の強さ、色域、境界のなじみ、選択色の彩度を調整
- 元画像との比較表示と、元サイズでのPNG出力
- PNG / JPG / WebP / GIF（先頭フレーム）に対応し、処理はブラウザ内で完結

## Text Reel

- 各列の設定内で専用のリール文字列を入力し、縦方向へループ
- 1列最大40文字・全体最大12列。列の追加・削除に対応
- 上向き・下向き・列ごとのランダム方向と、ランダムな開始位置に対応
- 列ごとに回転方向、回転速度、ループ継続または指定文字での確定、確定時刻を選択
- 全列が0秒から即回転。指定速度を保ちながら着地できるよう開始位置と減速時間を自動調整
- 即停止・なめらか・少し弾む停止動作を選択。演出が消えないよう最低動作時間を自動確保
- 中央と前後1文字の3段表示。確定文字の赤と中央枠の黄はDial Typeに準拠
- ゴシック・明朝・等幅書体と、端末内のローカルフォントに対応
- 最大90秒、1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力

書き出しには `HTMLCanvasElement.captureStream()` と `MediaRecorder` に対応したブラウザが必要です。
