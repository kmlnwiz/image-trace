# Motion Lab

ブラウザだけで動画素材を作成できるアニメーションツール集です。

## 起動

`index.html` をブラウザで開き、ホーム画面からツールを選択します。処理はブラウザ内で完結します。

各ツールの設定はブラウザのローカルストレージへ自動保存され、次回表示時に復元されます。読み込んだ画像ファイルと再生位置は保存されません。
Dial Typeで選択したローカルフォントはブラウザ内のIndexedDBへ保存され、外部には送信されません。

## Outline Motion

- PNG / WebP / GIF のアルファチャンネルから最大の連結要素を抽出
- プレビュー上のクリックによる輪郭始点の変更
- 輪郭の先頭と末尾をそれぞれ任意のパーセント間でアニメーション
- 100%を超える値による複数周の指定
- 再生速度、出力時間、イージング、線、背景、元画像濃度の調整
- 最大90秒、1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力

## Dial Type

- 入力した文字列をダイヤル錠風に表示
- 前後1文字から目的の文字へ戻るアニメーション
- 動かさない文字の個別指定
- 濁点・半濁点を右肩へ固定し、小書き文字を自動固定
- 初期方向、ずれ数、表示段数、復帰順、時間差、速度、イージング、ローカルフォント、配色の調整
- 固定文字と復帰済み文字を赤で表示し、中央の読取位置を枠で表示
- 最大90秒、1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力

## Reverse Kanji

- 漢字1文字を、最後の画から最初の画へ逆順で描画
- 各画も終点から始点へ逆向きに描画
- Hanzi Writer Japanese Dataの画輪郭と運筆中心線を利用し、正方向アニメーションを逆転
- 最大60秒の全体時間、画ごとのインターバル、イージング、下書き濃度、文字色、背景色の調整
- 1600 x 1000、60fps、WebM形式の動画出力
- 指定時刻のフレームをPNG形式で出力
- 日本語用のHanzi Writer Japanese Data（AnimCJK / Arphic Public License・LGPL）を使用（取得後はブラウザ内にキャッシュ）

書き出しには `HTMLCanvasElement.captureStream()` と `MediaRecorder` に対応したブラウザが必要です。
